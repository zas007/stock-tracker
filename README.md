# 台灣股市三大法人買超追蹤

自動抓取 TWSE 三大法人買超/賣超資料，寫入 Google Sheets，每日 16:30 自動執行。

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `fetch_and_update.py` | 主程式，每次更新換這個 |
| `backtest.py` | 回測程式，驗證推薦評分因子的歷史勝率 |
| `config.py` | 設定檔，族群、門檻、名稱對照，日常調整改這個 |
| `CHANGELOG.md` | 版本修改紀錄 |
| `WORKFLOW.md` | 開發流程規範（對話銜接方式、commit 格式） |
| `每日更新.sh` | 手動執行腳本 |
| `credentials.json` | ⛔ Google API 金鑰（本機保管，不在此 repo） |
| `log.txt` | ⛔ 執行記錄（本機保管，不在此 repo） |

## 快速開始

```bash
# 手動執行
cd ~/Documents/Z/study/stock
./每日更新.sh

# 查看 log
tail -30 ~/Documents/Z/study/stock/log.txt

# 查看 crontab（每天 16:30 自動執行）
crontab -l
```

## 換到新電腦時的設定

在新電腦（尤其是新的 Mac）第一次跑之前，通常要處理兩個環境問題：

1. **`./每日更新.sh` 出現 `Permission denied`**
   從別台電腦複製過去的檔案不會帶執行權限，執行一次即可（只需在這台電腦做一次）：
   ```bash
   chmod +x 每日更新.sh
   ```

2. **執行時出現 `ImportError: ...incompatible architecture (have 'x86_64', need 'arm64...')`**
   代表目前這個 Terminal／Python 環境裝的是 Intel(x86_64) 版本的 `cryptography` 等套件，但實際跑在 Apple Silicon(arm64) 的機器上。排查步驟：
   ```bash
   # 1. 確認 Terminal 是否被設定成用 Rosetta 開啟（回傳 i386 代表是，需改用原生模式開啟）
   arch

   # 2. 重新安裝成對應架構的版本
   pip3 install --user --force-reinstall --no-cache-dir cryptography gspread google-auth google-auth-oauthlib
   ```

| 工作表 | 說明 | 更新方式 |
|--------|------|----------|
| 今日買超排行 | 三法人買超前十名（含均價、收盤價、成交量、籌碼集中度） | 新資料插最上面 |
| 今日賣超排行 | 三法人賣超前十名（含均價、收盤價） | 新資料插最上面 |
| 歷史紀錄 | 所有買超/賣超逐行累積 | 每日新增，不覆蓋（保留 31 天） |
| 對照分析 | 完整統計（連續天數、加權均價、出貨風險、籌碼集中度、融資健康度） | 每次執行覆蓋 |
| 每日快照 | 每天統計快照，供跨日比較 | 新資料插最上面 |
| 族群聯動 | 買超榜觸發族群的全員行情（漲跌幅、成交量、是否在買超榜） | 新資料插最上面 |
| 明日關注 | 隔天觀察推薦榜（評分、連續天數、籌碼集中度、建議買進價位等） | 新資料插最上面（保留 31 天） |
| 推薦成效 | 追蹤「明日關注」推薦後 T+1～T+5 收盤表現，驗證推薦準不準 | 每次執行整表覆蓋（追蹤中清單） |
| 推薦歷史 | T+5 追蹤完畢後永久保存的推薦成效紀錄 | 每日新增，**永久保留，不受 31 天限制** |
| 警訊 | 大盤層級風險燈號（紅/黃/綠）＋出貨風險/融資健康度摘要 | 每日新增一列，新資料插最上面（保留 31 天） |
| 族群熱度 | 各產業族群買超連動的熱度分數與趨勢 | 每次執行覆蓋 |
| 融資歷史 | 各股融資餘額逐日快照 | 每日新增，不覆蓋（保留 31 天） |
| 融券歷史 | 各股融券餘額逐日快照 | 每日新增，不覆蓋（保留 31 天） |
| 成交量歷史 | 各股成交量逐日快照 | 每日新增，不覆蓋（保留 31 天） |
| 收盤價歷史 | 各股收盤價逐日快照 | 每日新增，不覆蓋（保留 31 天） |
| 重大訊息歷史 | 公開資訊觀測站重大訊息公告紀錄 | 每日新增，不覆蓋（保留 31 天） |
| 集保快取 | 集保戶股權分散表（大戶持股%）本地快取，避免重複打 API | 每次執行覆蓋 |
| 快取 | 程式內部暫存資料（今日行情、族群價格等），供 `--sheet-only` 模式使用 | 每次執行覆蓋 |
| 回測明細 | `backtest.py` 產出：每筆推薦的逐日回測明細 | 每次回測覆蓋 |
| 回測勝率 | `backtest.py` 產出：各評分因子切面的勝率矩陣 | 每次回測覆蓋 |
| 回測設定 | 手動填入代號，供「回測：單股」模式讀取 | 使用者手動維護，程式不寫入 |
